# Fonts Required

Place these font files here:
- `JetBrainsMono-Regular.ttf` — used for terminal rendering
- `JetBrainsMono-Bold.ttf` — used for bold terminal text

Download from: https://www.jetbrains.com/lp/mono/
GitHub: https://github.com/JetBrains/JetBrainsMono/releases

These are free, open-source fonts (SIL OFL 1.1 license).
